# سند RM SOFT — حزمة Android أصلية

هذه الحزمة تحول واجهة سند الحالية إلى تطبيق Android قابل للتثبيت (APK) باستخدام Capacitor، بدلاً من تشغيله كصفحة داخل Chrome. الواجهة الأصلية موجودة في `www/index.html` كما هي، مع جسر لإتاحة بعض إمكانات Android الأصلية.

## بناء APK بدون كمبيوتر باستخدام GitHub
1. أنشئ مستودعاً جديداً في GitHub.
2. فك ضغط ZIP وارفع **كل محتوياته** إلى جذر المستودع (تأكد أن مجلد `.github/workflows` مرفوع؛ قد تحتاج إظهار الملفات المخفية).
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build Sanad Android APK** ثم **Run workflow**، أو انتظر انتهاء البناء بعد رفع الملفات.
5. افتح نتيجة التشغيل الناجح، ثم من **Artifacts** نزّل `sanad-rmsoft-debug-apk`.
6. فك ضغط ملف Artifact، وثبّت `app-debug.apk` على هاتف Android، واسمح بالتثبيت من هذا المصدر عند طلب النظام.

## إمكانات Android الموجودة في الحزمة
- طلب إذن إشعارات Android 13+ عبر إضافة Capacitor الأصلية.
- إرسال إشعار محلي تجريبي.
- فحص البصمة/الوجه المتاحين للتطبيق، وفتح نافذة Android BiometricPrompt لاختبار التحقق.
- جسر تسجيل FCM لإشعارات Push.
- زر «إعدادات الجهاز» يظهر داخل التطبيق بعد تثبيته كتطبيق Android.

## إعداد Push الحقيقي
لتلقي إشعارات من الخادم عندما يكون التطبيق مغلقاً:
1. افتح Firebase Console وأنشئ/اختر مشروع Firebase.
2. أضف تطبيق Android بالمعرّف `com.rmsoft.sanad`.
3. نزّل `google-services.json` وضعه في `android/app/` بعد توليد مجلد Android محلياً، أو أضفه في المستودع داخل `android/app/` قبل البناء التالي. لا تضع مفاتيح خدمة Firebase الخاصة أو مفاتيح الخادم في HTML.
4. يلزم خادم موثوق يرسل رسائل FCM، وربط رمز الجهاز بحساب الموظف. هذه الحزمة تسجل الجهاز وتعرض رمز FCM للاختبار، لكنها لا تنشئ وحدها خدمة إرسال أو تربط كل أحداث النظام بالإشعارات.

## حدود مهمة بصراحة
- البصمة هنا اختبار أصلي لواجهة Android؛ لم تُربط بعد بتسجيل الدخول أو تخزين بيانات اعتماد الموظف بشكل آمن. لا تستخدمها كبديل لكلمة المرور قبل تنفيذ ربط مصادقة آمن.
- SMS وWhatsApp لا يرسلهما التطبيق مباشرة بمجرد أذونات Android. يلزم مزود خدمة وخادم خلفي ومفاتيح سرية محفوظة على الخادم.
- حسابات الموظفين المستقلة وصلاحياتها الآمنة تحتاج Backend وقواعد قاعدة بيانات؛ لا يعني تغليف HTML أن بيانات الموظفين أصبحت معزولة أو آمنة تلقائياً.
- ملف APK الناتج من GitHub Actions هو **Debug APK** للتجربة والتثبيت اليدوي، وليس إصداراً منشوراً على Google Play. النشر العام يحتاج توقيع Release بمفتاح خاص محفوظ في GitHub Secrets.
- لم يتم بناء APK داخل هذه الجلسة؛ GitHub Actions سيبنيه بعد رفع المشروع. لا تعتبره مثبتاً قبل تنزيل APK وتجربته على جهازك.

## الملفات الأساسية
- `www/index.html`: تطبيق سند الحالي.
- `native.js`: ربط الإشعارات والبصمة الأصلية.
- `capacitor.config.ts`: هوية التطبيق وإعدادات Capacitor.
- `.github/workflows/android-apk.yml`: بناء APK آلياً.
